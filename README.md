# San Francisco International Airport (SFO) Air Passenger Traffic Analysis (Python EDA)

Exploratory data analysis of **SFO monthly air passenger traffic** using pandas to clean, aggregate, and visualize patterns in arrivals/departures, domestic vs. international mix, airline concentration, and transit share.

## Case Study (visual write-up)

https://krrusha.github.io/San-Francisco-Air-Traffic-Analysis/

> **Note:** For the full notebook workflow and code, see **analysis.ipynb** in this repo.

## Highlights

- Analyzed **summer (June–August)** arrival trends from **2015–2024** to capture seasonality and post-2020 recovery.
- Compared **domestic vs. international** arrival volumes over time to understand traffic composition shifts.
- Identified the **top airlines for international departures (2020–2024)** to show concentration and carrier mix.
- Measured **transit passenger share** to evaluate whether SFO behaves more like a transit hub or an origin/destination airport.

## Tech Stack

- Python (pandas, numpy)
- Matplotlib
- Jupyter Notebook
